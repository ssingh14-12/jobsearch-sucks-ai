# /docs — Soumya's Vault

Drop your documents here. Claude reads everything in this folder at the start of each session.

## What goes where

| File/Folder | What to put there |
|---|---|
| `holy_grail.docx` | Your Holy Grail rules document (§1–§13) |
| `linkedin.pdf` | Export from LinkedIn → Settings → Data Privacy → Export your data |
| `writing_context.md` | Your voice, tone, banned words, style preferences |
| `resumes/` | All your resume versions (PDF or DOCX). Name them clearly e.g. `resume_pm_2025.docx` |
| `outreach_examples/` | Real LinkedIn messages you've sent — connection requests, cold emails, recruiter DMs |

## How to export LinkedIn PDF
1. Go to linkedin.com → Me → Settings & Privacy
2. Data Privacy → Get a copy of your data
3. Select "Want something in particular?" → Profile
4. Download and drop the PDF here
